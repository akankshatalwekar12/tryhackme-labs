What I Learned

I learned how Windows systems contain different artifacts that can provide information about user and system activity.

I also learned that investigators can correlate different artifacts and timestamps to understand what happened during a security incident.

SOC Relevance

Windows forensics is useful for SOC analysts during incident investigation. Analysts can examine endpoint activity and system artifacts to understand suspicious behavior and support incident response.

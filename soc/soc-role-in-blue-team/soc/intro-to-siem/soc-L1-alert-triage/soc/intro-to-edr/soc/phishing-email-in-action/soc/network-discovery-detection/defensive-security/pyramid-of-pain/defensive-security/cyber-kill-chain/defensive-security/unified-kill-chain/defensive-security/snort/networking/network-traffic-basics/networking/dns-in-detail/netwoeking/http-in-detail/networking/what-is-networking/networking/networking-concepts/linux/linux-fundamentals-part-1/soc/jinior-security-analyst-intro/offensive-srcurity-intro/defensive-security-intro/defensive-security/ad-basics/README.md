TryHackMe – AD Basics

Room Overview

This room introduces the fundamentals of Microsoft Active Directory (AD) and explains how organizations manage users, computers, groups, and resources in a Windows domain environment.

What I Learned

I learned the basic structure and purpose of Active Directory and how it is used to manage identities, computers, and resources in an organization.

I also learned the importance of authentication, authorization, and policies in a Windows domain environment.

SOC Relevance

Active Directory knowledge is important for SOC analysts because many enterprise security incidents involve user accounts, authentication events, privileges, and domain systems.

Pyramid of Pain

The Pyramid of Pain shows that different indicators have different levels of difficulty for attackers to change.

        TTPs
       Tools
   Network / Host Artifacts
      Domain Names
       IP Addresses

What I Learned

I learned that defenders can use different indicators to detect malicious activity.

Lower-level indicators such as file hashes can be useful for detection, while higher-level indicators such as attacker TTPs can provide broader information about adversary behavior.

SOC Relevance

Understanding IOCs and attacker behavior helps SOC analysts investigate alerts, identify malicious activity, and improve detection capabilities.
